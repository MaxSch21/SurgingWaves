🌊 Surging Waves 🌊

Unity 6.3 LTS (6000.3.27f2) HDRP

Wichtige Regeln

1. Immer in der eigenen Scene arbeiten
    - Create your own folder inside Assets/Scenes/ (e.g. Scenes/YourName/)
    - Copy an existing scene (e.g. SurgingWaves_Demo) into your folder and rename it
    - Do not modify shared or other people's scenes without discussing it first

2. Use Prefabs!
    - for objects used in multiple scenes
    - Store somewhere in the Prefabs Folder
    - Make changes to shared Prefabs carefully, as they can affect multiple scenes
    - Coordinate major changes with the team

3. GitHub & VersionControl
    - Avoid directly pushing to main without discussing it first
    - Ideally, create your own branch for your work
    - Use clear, descriptive commit messages
    - Coordinate changes to shared files and scenes
    - Merge changes into main only after they have been reviewed or agreed upon (mergen werd dann wsl ich machen ^^ -Max)

If you're unsure about something, ask the team before making major changes! 🐳
